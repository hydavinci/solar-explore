# Solar Explore · SOLAR 太阳系探索器

以真实尺度漫游为主的浏览器太阳系项目。默认从地球近景开始，支持太阳、八大行星和月球，以及可切换的示意模式。另提供六艘航天器的任务资料与独立三维模型预览，并接入旅行者1号木星飞掠的真实档案轨迹。

基于 **React、TypeScript、Three.js / React Three Fiber、Astronomy Engine 和 Vite**。纯前端运行，无账户、API 密钥或业务后端；纹理和已发布的轨迹数值随项目提供。

## 功能概览

- **太阳系探索**：真实与示意尺度切换，搜索定位、平滑飞近、环绕、自由飞行和跟随。
- **时间控制**：暂停、加速、倒放、跳转 UTC 日期，支持 1800 年至 2050 年之前的日期。
- **航天器档案**：六艘任务资料、官方来源和可独立旋转/缩放的原创三维示意模型。
- **真实历史航迹**：旅行者1号 1979 年木星飞掠回放，包含同源木星位置、覆盖边界与数据来源说明，不伪造其他航天器的位置。
- **显示与恢复**：本地行星纹理、土星环、轨道和标签开关、两档画质、资源重试与 WebGL 上下文恢复。

## 本地运行

本项目使用 npm lockfile。开发环境为 Node.js 26.7.0 / npm 11.19.0；Vite 要求 Node.js 20.19+ 或 22.12+ 的受支持版本。浏览器需要支持 WebGL 2；普通运行不需要 Python 或在线 NASA 星历服务。

```bash
git clone https://github.com/hydavinci/solar-explore.git
cd solar-explore
npm ci
npm run dev
```

打开终端显示的本地地址。默认仅监听 `127.0.0.1`，不向局域网暴露。

### 开发与验证命令

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

浏览器流程使用本机已安装的 Google Chrome。默认自动启动或复用 `127.0.0.1:4173` 的开发服务：

```bash
npm run test:e2e
```

也可通过 `PLAYWRIGHT_BASE_URL` 指向已有服务；生产构建的浏览器运行方式见下方“静态发布”。只有重新生成历史轨迹时才需要独立的 Python / SpiceyPy 环境，具体步骤见 `docs/data-sources.md`。

## 操作

| 操作 | 方法 |
| --- | --- |
| 选择并聚焦天体 | 单击左侧天体列表或搜索结果，自动平滑飞近并进入环绕 |
| 航天器资料 | 左侧切换“航天器”，支持中英文搜索；没有当前有效轨迹时只更新资料 |
| 历史轨迹 | 选择“旅行者1号”→“回放木星飞掠”，主动跳到历史日期；有效回放中可飞近、环绕或跟随 |
| 航天器模型 | “查看三维模型”打开独立预览，左键旋转、滚轮缩放、Esc 关闭 |
| 场景内选择 | 左键单击天体、航天器定位点或标签仅更新选中项，不移动镜头；拖动超过 5 像素不触发选择 |
| 飞向目标 | 飞向按钮或 G；航天器须有当前已启用的有效历史回放 |
| 环绕观察 | 左键拖动，滚轮缩放；达到最近安全距离后仍可反向滚轮拉远 |
| 自由飞行 | 切换自由模式，W/A/S/D 移动、Q/E 升降、右键观察、滚轮调速 |
| 跟随 | 真实尺度下保持相对目标位置，不随天体自转旋转 |
| 时间 | 底部暂停、正反倍率、日期和“回到现在” |
| 界面 | H 隐藏/恢复，/ 搜索，Esc 取消飞向 |
| 画质 | 右上角画面设置，标准/流畅，标签/轨道开关 |

真实尺度下远处行星可能小于一个像素，这不是丢失。使用标签或搜索飞近；示意模式对尺寸和距离做非线性调整，不改变天文状态。

### 航天器与首段真实轨迹

已加入旅行者1号、旅行者2号、卡西尼号、朱诺号、新视野号和天问一号。资料包含机构、发射日期、任务简介、主要事件、关联天体、官方来源与核验日期；不随模拟时钟伪装成实时情报。

模型为原创轻量外观示意，非工程模型、非实时姿态。旅行者1/2共用基础外形，天问一号仅表示环绕器。预览按需渲染，关闭后释放资源；操作与错误均隔离于太阳系主场景。

**旅行者1号已接入 1979 年 2 月 6 日至 4 月 8 日的木星飞掠档案，共六个有效数据段。** 来源为 NASA PDS 保存的 `VG1-J-SPICE-6-SPK-V2.0`，浏览器读取本地约 80 KB 的派生数值，不访问在线星历 API。

使用“回放木星飞掠”会跳至 **1979-03-05 12:00 UTC**，设为暂停、3600 倍倍率并飞近；点击底部“继续”播放，也可倒放。这个预设日期不是精确最近接近时刻。暖色线为航迹，小方点是非实际尺寸的航天器定位点；独立预览仍用于查看三维外观。

回放期间，木星也使用同份档案的参考位置，避免与现有近似行星模型直接混用。退出时恢复原木星模型，保留当前日期。有效覆盖内从列表选择航天器可以启用当前日期回放；覆盖外不会自动改时间。自然播放跨越数据段边界会暂停并退出，手动设置日期则尊重输入；无有效位置时移除航天器和航迹，不外推或保留静止替身。

真实尺度使用相机相对物理坐标；示意模式将航天器及航迹统一映射到木星局部尺度，远段可能超出固定太阳系全景，可飞近观察。所有距离读数仍是物理距离。回放时隐藏木星原近似辅助轨道线；其他天体和安全碰撞规则不变。

这是早期**历史导航星历**：原档未逐段区分重建/预测属性，也未提供绝对定轨误差，不宣称当前实时位置或全部事后重建。90,847 个检查时刻的最大源重现位置误差约为航天器 **0.237 km**、木星 **0.020 km**，不是绝对轨迹精度。原档限制、精确分段、校验和及重新生成方法见 `docs/data-sources.md`。

其余五艘仍只有资料和独立模型预览，没有虚构的位置、距离或路线；待实际取得并核验数据后逐艘接入。

## 范围与限制

- 纯前端，无账户、遥测或在线星历依赖；纹理本地打包。
- 时间范围：UTC 1800-01-01（含）至 2050-01-01（不含）。
- 常规行星轨道采用 Astronomy Engine；旅行者1号回放期间的木星采用同源档案位置。不是实时多体引力模拟。
- 自转、表面朝向、大气和曝光属于近似可视化；不用作航天导航、精密食相预测或测光。
- 不提供地形、着陆、完整星表、可驾驶飞船或银河导航；也不提供六艘航天器的完整任务航迹。
- 首要验收环境为用户指定的 Mac mini / 16 GB / Chrome；手机仅有基础布局适配。
- 性能目标和实际测量分开记录，见 `docs/performance.md`；没有实机证据不承诺 60 FPS。

## 静态发布

构建输出位于 `dist/`，可部署到任意支持静态文件的服务器。不需要 Node.js 业务后端。

```bash
# 部署到域名的 /solar/ 路径
npm run build -- --base=/solar/
npm run preview -- --base=/solar/
```

资源都从构建的 `BASE_URL` 加载。生产浏览器验收可指定：

```bash
PLAYWRIGHT_BASE_URL=http://127.0.0.1:4173/solar/ \
PLAYWRIGHT_SERVER_COMMAND="npm run preview -- --port 4173 --base=/solar/" \
npm run test:e2e
```

## 工程结构

- `src/simulation/`：天文数据、坐标与时钟。
- `src/navigation/`：镜头、输入、路径与安全距离。
- `src/rendering/`：相机相对渲染、天体效果、画质。
- `src/spacecraft/`：资料目录、原创预览模型、本地星历加载/校验/插值，不混入行星物理目录。
- `public/trajectories/`：已验证的派生状态数值；原始 SPK/LSK 不在发布包内。
- `scripts/import_voyager1.py`：可选离线导入工具；正常前端运行不需要 Python。
- `src/assets/`：纹理清单、加载缓存。
- `src/ui/`：搜索、时间、资料、设置与帮助。
- `tests/e2e/`：真实 Chrome 操作与恢复流程。

设计与实施计划保存在 `docs/superpowers/`。阶段状态以实际实现与验收记录为准，不以计划中的任务描述为完成证明。
