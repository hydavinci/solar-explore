# 性能测量

标准档目标：内部渲染最多 1920×1080，热缓存帧时间中位数 ≤16.7 ms，P95 ≤22 ms。低档最多 1280×720，保留导航与时间功能。

目标设备由用户指定为 Mac mini / M5 / 16 GB / Chrome。自动化宿主不因同为 macOS 就视为同一设备；只有实际证据可以证明目标达标。

## 复现方法

```bash
npm run build
npm run preview -- --port 4173
# 在另一个终端执行；默认每视角预热10秒、采样60秒
SOLAR_HEADED=1 node scripts/measure.mjs
```

脚本固定视口、模拟时间和相机目标，记录地球、土星、太阳及全景的帧时间、Chrome user agent、WebGL renderer 和实际 canvas 像素尺寸。截图与 JSON 写入被忽略的 `.artifacts/performance/`，避免 Playwright 清理其测试目录时丢失独立测量证据。可用 `SOLAR_URL` 指向子路径生产部署。

无头模式仅用于回归诊断，不代替前台真实交互验收。缩短采样的结果不得标为正式验收。

## 资源稳定性

启用“画面设置 → 诊断信息”，反复地球→土星→海王星→地球十次，在第1、5、10次记录纹理、几何和估计缓存。允许初次访问增长，但达到缓存稳定态后不应逐轮增长。纹理估算并非整个进程内存，也不是精确 GPU 内存。

当前正式目标设备验收状态：待用户指定设备实测。

## 集成阶段实测

实际自动化宿主：WebGL 报告 Apple M4，Chrome 155，无头模式。内部渲染 1920×1080，标准画质；模拟日期固定为 2026-10-13 12:00 UTC。每视角预热 10 秒、采样 60 秒，按浏览器 RAF 间隔测量。

| 场景 | 帧数 | 中位帧时间 | P95 |
| --- | ---: | ---: | ---: |
| 地球近景 | 3601 | 16.7 ms | 16.8 ms |
| 土星近景 | 3602 | 16.7 ms | 16.8 ms |
| 太阳近景 | 3601 | 16.7 ms | 16.8 ms |
| 太阳系全景 | 3601 | 16.7 ms | 16.8 ms |

期间无页面异常。该结果支持此宿主、当前场景下约 60 FPS，不代表用户 M5 设备已验收，也不证明任意窗口、场景或后台负载下都保持该帧率。RAF 间隔不是 GPU 独立执行时间。原始 JSON 与截图位于 `.artifacts/performance/`；本表为滚轮、图形生命周期和土星完整环取景修复后的复测结果。

自动往返与缓存记录：

```bash
node scripts/stability.mjs
```

执行十轮四段飞行，并记录第1、5、10轮的缓存及诊断计数。该脚本在测量脚本完成后单独运行，避免两个浏览器竞争 GPU 影响帧时间。

最终实现代理的十轮生产运行在第1、5、10轮均记录缓存估算为 65,762,652 字节，未出现逐轮增长；原始连续状态保存在 `.artifacts/stability/` 的成功运行子目录。父任务独立复验曾出现采样断档：最后一次观测仍在飞行，超时后实际场景已到达地球，不能仅凭断档断言导航算法停滞。Node 观测端被阻塞的受控实验可产生相似现象，但不能据此认定原事件的唯一原因。采样脚本保留请求/响应时刻、独立心跳及浏览器时钟，超时仍返回失败，不延长截止时间或将事后到达当成成功。
